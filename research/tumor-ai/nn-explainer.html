From one neuron to our 3D U-Net

How a neural network works, built up from the smallest piece: a single neuron that can act like an AND or OR gate, why it fails at XOR, how a network learns its own weights, and how the same idea grows into the 3D U-Net we wrote to outline lung tumours on CT.

Step 1

A neuron is a weighted vote

A neuron takes some numbers in, multiplies each by a weight (how much it cares about that input), adds them up with a bias (its starting lean), and passes the total through an activation that decides how strongly to fire.

The weights and bias are the knobs. Training a network means finding good knob settings. Our U-Net is this same idea repeated with 1.4 million knobs.
Step 2

One neuron can be an AND or an OR gate

Inputs are 0 or 1. The activation here is a step: output 1 if the total is above 0, otherwise 0. Move the knobs, or load a preset, and watch the truth table and the dividing line. A single neuron always draws one straight line: points on one side give 1, the other side 0.

Step 3

XOR breaks a single neuron

XOR means "one or the other, but not both": (0,1) and (1,0) give 1; (0,0) and (1,1) give 0. Try it above: no setting works. The two 1-points sit on opposite corners, and no single straight line can put them on one side and the two 0-points on the other.

The fix is to stack neurons in layers. Two hidden neurons each draw one line, and an output neuron combines them:

  • hidden neuron A = OR (x₁, x₂)
  • hidden neuron B = NAND (x₁, x₂), "not both"
  • output = AND (A, B) → that is exactly XOR

This is why "deep" learning stacks layers: each layer builds new features out of the previous layer's, until a straight line in the new features is enough.

Step 4

Learning: the network finds its own weights

Above, we chose the weights by hand. Real networks have far too many knobs for that, so they learn them with a loop that repeats thousands of times:

The same network in PyTorch

import torch
from torch import nn

X = torch.tensor([[0., 0], [0, 1], [1, 0], [1, 1]])
y = torch.tensor([[0.], [1], [1], [0]])        # answer key

net = nn.Sequential(nn.Linear(2, 4), nn.Tanh(),  # hidden layer
                    nn.Linear(4, 1), nn.Sigmoid()) # output
opt = torch.optim.SGD(net.parameters(), lr=0.5)
loss_fn = nn.BCELoss()

for step in range(2000):
    loss = loss_fn(net(X), y)   # 1 guess, 2 how wrong
    opt.zero_grad()
    loss.backward()             # 3 who caused it
    opt.step()                  # 4 nudge knobs

print(net(X).round())  # → 0, 1, 1, 0

Tested: after 2,000 steps the loss is 0.0013 and the answers are 0, 1, 1, 0.

What the words mean

Loss: one number for "how wrong". It should go down.

Backpropagation: works backwards from the loss to find how much each knob contributed. PyTorch does this for us in loss.backward().

Optimizer: moves every knob a small step in the direction that lowers the loss (gradient descent).

Activation: here Tanh and Sigmoid are smooth versions of the step, because learning needs smooth slopes to follow.

Encoder or decoder? Neither. This tiny network is just layers in a row. Encoder and decoder appear in the U-Net (step 7): the encoder shrinks the image to understand it, and the decoder grows it back to draw the outline.
Step 5

Images are grids of numbers, read by sliding filters

A CT slice is a 512 × 512 grid of numbers in Hounsfield units: air −1000, water 0, soft tissue and tumour around 0 to +100, bone +400 and up. A tumour in the lung is a bright patch in a dark field.

Giving every pixel its own weight would need millions of knobs per neuron and would not recognise the same shape in a different place. A convolution instead slides one small filter (here 3 × 3, so 9 knobs) over the whole image, computing a weighted sum at every position. The same filter finds the same pattern anywhere.

Input values are scaled: 0 = lung (dark), 9 = tumour (bright). The edge filter lights up the tumour's border. In a network the filter values are not hand-picked: they are knobs, learned in training.

Our scans are 3D, so our filters are 3 × 3 × 3 cubes (27 knobs each) that slide through the volume, seeing a tumour as a ball and a blood vessel as a tube.

class Block(nn.Sequential):
    """Two rounds of: 3x3x3 conv -> normalise -> activation."""
    def __init__(self, cin, cout):
        super().__init__(
            nn.Conv3d(cin, cout, 3, padding=1),
            nn.InstanceNorm3d(cout, affine=True),
            nn.LeakyReLU(0.01, inplace=True),
            nn.Conv3d(cout, cout, 3, padding=1),
            nn.InstanceNorm3d(cout, affine=True),
            nn.LeakyReLU(0.01, inplace=True),
        )

One Block is the U-Net's basic unit: two convolutions, each followed by normalisation and activation. It is the 3D, many-channel version of the neuron in step 1: weighted sums, then "fire or not".

Step 7

Our 3D U-Net, layer by layer

Shapes are written channels × depth × height × width, for one input block of 32 slices × 128 × 128 pixels. Going down the U the image shrinks and the number of feature maps doubles (it learns what is there). Going up it grows back (it learns where). Skip connections carry the sharp detail across.

Why these choices

First shrink is flat, (1,2,2). Our slices are 3 mm apart but pixels are about 1 mm. Shrinking only across the slice first makes the voxels nearly cubes (about 2 × 2 × 3 mm) before shrinking in all directions.

Channels double as size halves: 16 → 32 → 64 → 128. Smaller images, but more kinds of pattern.

3D, not 2D: on one slice a vessel and a tumour can look alike; across slices a vessel is a tube and a tumour a ball.

1.40 million knobs at base=16. On HPC we use base=32, about 4 times more.

def forward(self, x):
    skips = []
    for i, enc in enumerate(self.enc):     # going down
        x = enc(x)
        if i < len(self.pool):
            skips.append(x)                   # keep for later
            x = self.pool[i](x)               # shrink
    for i in reversed(range(len(self.up))):  # going up
        up = self.up[i](x)                    # grow
        x = self.dec[i](torch.cat([up, skips[i]], dim=1))
    return self.head(x)                      # 2 scores per voxel
